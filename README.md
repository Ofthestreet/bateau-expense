# ⛵ Bateau Expense

**EN** | [FR](#fr)

A Progressive Web App (PWA) to track and split shared expenses on a boat trip. Works offline, installable on iPhone and Android — no App Store, no Apple account needed.

### Features
- Add participants with visual chips
- Log expenses with description, amount, and who paid
- Automatically splits costs among selected participants
- Balance view showing who owes what
- Optimal settlement calculation (minimum number of transfers)
- Data saved locally on your device (localStorage)
- Works fully offline

### Live App
👉 **https://ofthestreet.github.io/bateau-expense/**

### Install on iPhone
1. Open the URL above in **Safari**
2. Tap the **Share** button (square with arrow ↑)
3. Tap **"Add to Home Screen"**
4. Tap **Add**

### Install on Android
1. Open the URL in **Chrome**
2. Tap the **⋮** menu
3. Tap **"Add to Home Screen"**

### Tech Stack
- Vanilla HTML / CSS / JavaScript (no framework)
- PWA with Service Worker for offline support
- Auto-deployed via GitHub Actions → GitHub Pages

## FR

Application web progressive (PWA) pour suivre et partager les dépenses lors d'une sortie en bateau. Fonctionne hors-ligne, installable sur iPhone et Android — sans App Store, sans compte Apple.

### Fonctionnalités
- Ajout de participants sous forme de chips visuels
- Enregistrement des dépenses avec description, montant et payeur
- Répartition automatique des coûts entre les participants sélectionnés
- Vue bilan affichant les soldes de chacun
- Calcul optimal des remboursements (nombre minimum de virements)
- Données sauvegardées localement sur l'appareil
- Fonctionne entièrement hors-ligne

### Application en ligne
👉 **https://ofthestreet.github.io/bateau-expense/**

### Installer sur iPhone
1. Ouvrez l'URL ci-dessus dans **Safari**
2. Appuyez sur **Partager** (carré avec flèche ↑)
3. Appuyez sur **"Sur l'écran d'accueil"**
4. Appuyez sur **Ajouter**

### Installer sur Android
1. Ouvrez l'URL dans **Chrome**
2. Appuyez sur les **⋮** (trois points)
3. Appuyez sur **"Ajouter à l'écran d'accueil"**

### Stack technique
- HTML / CSS / JavaScript natif (sans framework)
- PWA avec Service Worker pour le mode hors-ligne
- Déploiement automatique via GitHub Actions → GitHub Pages
